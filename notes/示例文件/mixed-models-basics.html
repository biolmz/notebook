线性混合模型笔记：为什么重复测量不能直接跑 t 检验

2026-04-19 统计 线性混合模型，lme4，重复测量

起因是把一个实验的数据直接拿去做 t 检验，被指出犯了“伪重复”（pseudoreplication）的错。 这篇把当时没想通的地方重新推一遍，顺便对比 R 和 Python 两套写法。

场景

12 只小鼠，随机分两组（给药 / 对照），每只小鼠在第 0、7、14 天各测一次体重。 总共 36 个观测值，但独立个体只有 12 个 —— 同一只小鼠的三次测量之间天然相关， 它自己的基线在哪儿，很大程度上决定了后面三次都在哪儿。

如果把这 36 个观测当成 36 个独立样本跑 t 检验，标准误会被低估， p 值偏小，看起来“显著”的差异可能只是个体差异被当成了组间差异。 数据点个数没变，信息量却虚高了。

固定效应和随机效应的区别

判断一个因子该放哪边，我的记法是：取值本身是否被我们穷举、而且每个水平都要单独解释， 是固定效应；只是从一个更大的总体里抽样出来的、我们不关心每个水平具体是多少，是随机效应。

因子类型理由
处理组（给药 / 对照）固定效应只有这两个水平，每个都要报告效应大小
时间（0 / 7 / 14 天）固定效应三个时间点是设计好的，不是抽样得到的
小鼠个体随机效应12 只是从更大的种群抽的，只是要吸收掉个体差异

随机效应把“每只小鼠有自己的基线偏移”这件事显式写进模型， 这样这部分变异就不会被错误地算进误差项里。

R：lme4

In [5]
library(lme4)

# (1 | mouse) 表示“每只小鼠一个随机截距”，斜率共用
m1 <- lmer(weight ~ treatment * day + (1 | mouse), data = d)
summary(m1)

# 固定效应的 p 值：lme4 本身不给，要靠 lmerTest 的 Satterthwaite 近似自由度
library(lmerTest)
summary(as(m1, "lmerModLmerTest"))

Python：statsmodels

In [7]
import statsmodels.formula.api as smf

# groups 指定随机截距的分组变量，vc_formula 默认就是一个随机截距
m2 = smf.mixedlm("weight ~ treatment * day", d, groups=d["mouse"]).fit(reml=True)
print(m2.summary())

# 组内相关系数：个体差异占总变异的比例
icc = m2.cov_re.values[0, 0] / (m2.cov_re.values[0, 0] + m2.scale)
print(f"ICC = {icc:.3f}")
Out[7]
ICC = 0.873

ICC ≈ 0.87 意味着个体之间的差异解释了约 87% 的总变异。 换句话说不考虑个体差异的话，几乎就是在测“哪只小鼠”，而不是“药物有没有用”。

还没想明白的

  • 随机截距还是随机斜率。 现在的模型假设所有小鼠的体重随时间变化速度一样（斜率共用）。 如果某些小鼠长得快、某些长得慢，就该写 (day | mouse)。 但加了随机斜率之后参数变多，数据只有 36 个点，容易过拟合或者不收敛。
  • 自由度到底是多少。 lme4 不报 p 值就是因为分母自由度没有唯一正确答案， Satterthwaite / Kenward-Roger / 参数自助法是三种近似，小样本下结果会不一样。 我准备下次把这三种都跑一遍，看差异有多大。
  • 收敛警告。 第一次跑的时候报了 boundary (singular) fit， 原因是把随机效应写得太复杂、数据撑不住。简化之后消失。 这种警告不要忽略。

小结

重复测量数据里，个体差异不是噪声而是结构。混合模型做的事就是把 “谁被重复测了”这件事写进模型，代价是多出一层方差成分要估。 数据点少的时候，少加随机斜率、只用随机截距通常更稳妥。
